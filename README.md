# BAE — Binaural Audio Editor

**B**inaural **A**udio **E**ditor — веб-редактор для створення бінауральних записів без бінауральних мікрофонів.
Ви розставляєте звуки навколо слухача — попереду, позаду, вище, далеко, за стіною — і чуєте в навушниках так,
ніби все звучить наживо. *BAE — звук, що тебе обіймає.*

## Можливості

**Простір**
- Сцена згори: перетягуйте джерела й голову слухача, задавайте висоту (коліщатко миші) і поворот голови.
- HRTF-панорамування (Web Audio `PannerNode`, модель `HRTF`) для кожного джерела.
- Відстань: загасання гучності, поглинання високих частот повітрям, співвідношення прямого звуку й реверберації.
- Перешкоди: стіни з бетону, дерева чи тканини глушать і приглушують звук за ними.
- Приміщення: студія, кімната, концертний зал, собор, відкрите поле. Ранні відбиття від стін, підлоги й стелі
  рахуються методом уявних джерел, кожне зі своїм HRTF; плюс згенерована реверберація.
- Рух: готові траєкторії (коло, маятник, наближення, вгору-вниз) або **запис руху** — під час відтворення
  тягніть джерело мишею, і шлях запишеться в часі.

**Запис і монтаж**
- Запис з мікрофона на доріжку (кнопка **R** у мікшері) або на нову доріжку, з компенсацією затримки.
  Шумозаглушення й автогучність вимкнені, щоб зберегти чистий сигнал.
- Часова шкала професійного рівня:
  - кліпи з гейном (−24…+24 dB), фейдами на вході й виході, вимкненням, реверсом і нормалізацією (без зміни аудіо);
  - множинний вибір (Shift / Ctrl + клік, рамка), переміщення групою між доріжками, копія через Ctrl + перетягування;
  - обрізка країв, розрізання, копіювання / вирізання / вставка, дублювання, зсув стрілками;
  - прив'язка до сітки (такт, доля, 1/8, 1/16, 0,1 с) і «магніт» до країв кліпів, плейхеда, маркерів і меж циклу;
  - маркери з назвами й перехід між ними, цикл, метроном, шкала в тактах або хв:сек;
  - доріжки: кнопки M / S / R / 3D у заголовку, перестановка перетягуванням, дублювання, зміна висоти;
  - контекстне меню (правий клік) і перейменування подвійним кліком.
- Скасування / повтор (Ctrl Z / Ctrl Shift Z).

**Зведення**
- Канальні лінійки: фейдер, M / S, 3-смуговий еквалайзер, посил на реверберацію, індикатори рівня.
- Будь-яку доріжку можна перемкнути в звичайне стерео з панорамою (режим **ST**).
- Експорт бінаурального міксу у WAV 24 біт / 48 кГц.

**Проєкти**
- Бібліотека проєктів у браузері (IndexedDB) з автозбереженням кожні 20 с.
- Файл проєкту `.bae.zip` (project.json + аудіо у WAV) — для перенесення на інший комп'ютер.

## Запуск

Потрібен будь-який статичний веб-сервер (ES-модулі не працюють з `file://`):

```bash
python3 -m http.server 8000
```

Відкрийте <http://localhost:8000>. Для запису з мікрофона сторінка має бути на `localhost` або `https://`.

Публікація: GitHub Pages (Settings → Pages → гілка `main`, корінь) — збирання не потрібне.

## Гарячі клавіші

Працюють за будь-якої розкладки. Повний список у застосунку: кнопка «Клавіші ?» або клавіша `?`.

| Клавіша | Дія |
|---|---|
| Пробіл | відтворення / пауза |
| R | запис з мікрофона |
| Home / End | на початок / в кінець |
| ← / → | плейхед на крок сітки (Shift — на такт); з вибраними кліпами — зсув кліпів (Alt — 10 мс) |
| [ / ] | попередній / наступний маркер |
| ↑ / ↓ | попередня / наступна доріжка |
| S | розрізати в позиції плейхеда |
| Delete | видалити вибрані кліпи |
| Ctrl C / X / V / D | копіювати / вирізати / вставити / дублювати |
| Ctrl A, Esc | виділити все, зняти виділення |
| U | вимкнути / увімкнути кліп |
| M | маркер |
| L, I, O | цикл, початок циклу, кінець циклу |
| K | метроном |
| G | прив'язка до сітки |
| N | нова доріжка |
| = / − / Z | масштаб / вмістити проєкт |
| Ctrl Z, Ctrl Shift Z | скасувати, повторити |
| Ctrl S / Ctrl O / Ctrl E | зберегти / бібліотека / експорт WAV |

## Структура

```
index.html        розмітка
css/style.css     стилі (світла й темна теми)
js/main.js        інтерфейс і зв'язування модулів
js/engine.js      аудіограф, відтворення, рендер міксу
js/spatial.js     геометрія простору: позиції, перешкоди, відбиття
js/stage.js       сцена згори (canvas)
js/timeline.js    часова шкала (canvas)
js/recorder.js    запис з мікрофона (AudioWorklet)
js/state.js       модель проєкту, скасування / повтор
js/fileio.js      WAV, ZIP, IndexedDB
js/demo.js        синтезований демо-проєкт
js/peaks.js       кеш хвильових форм
```

## Обмеження

- Використовується стандартний HRTF браузера, а не індивідуальний: у деяких людей відчуття «спереду / позаду»
  слабше, ніж на справжньому бінауральному записі.
- Приміщення прямокутні; поширення звуку крізь двері між кімнатами поки не моделюється.
